KEY CHANGES:

AUTHENTICATION:
- Supabase OTP → Firebase Email Verification Links
- signInWithPassword → signInWithEmailAndPassword
- signUp → createUserWithEmailAndPassword
- resetPasswordForEmail → sendPasswordResetEmail
- updateUser → updatePassword
- onAuthStateChange → onAuthStateChanged
- getSession → auth.currentUser

DATABASE:
- from().select() → getDocs(query(collection(db, ...)))
- from().insert() → addDoc(collection(db, ...))
- from().update().eq() → updateDoc(doc(db, ...))
- from().delete().eq() → deleteDoc(doc(db, ...))
- .eq() filtering → where() clauses in queries
- Batch operations → writeBatch(db) for multi-document updates
