# ATPLVector brand assets

- `icon.png`: 1024 px opaque master icon for native icon generators.
- `icon-foreground.png`: transparent safe-zone foreground for Android adaptive icons.
- `icon-background.png`: dark navy adaptive-icon background.
- `ios/AppIcon-1024.png`: App Store icon master.
- `android/mipmap-*`: ready-to-copy Android legacy, round, and adaptive foreground icons.
- `android/mipmap-anydpi-v26`: adaptive icon definitions.
- `android/values`: launcher background colour.

The live iOS project icon is stored in `ios/App/App/Assets.xcassets/AppIcon.appiconset`.
The website and PWA icons are stored in `public/icons`, with `public/favicon.ico` for browser compatibility.
